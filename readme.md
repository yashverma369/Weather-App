## 📌 Overview

This project lets users search for any city and instantly view its current weather conditions — temperature, humidity, wind speed, and a dynamic weather icon that changes based on real-time conditions (clear, cloudy, rainy, drizzle, or misty).

## ✨ Features

- 🔍 **Search any city** worldwide and get instant weather updates
- 🌡️ **Live temperature, humidity, and wind speed** data
- 🖼️ **Dynamic weather icons** that update based on current conditions
- ⚠️ **Error handling** for invalid city names
- 📱 **Responsive glassmorphism UI** with a smooth gradient background
- ⌨️ Search by clicking the button or pressing **Enter**

## 🛠️ Built With

- **HTML5** — Structure and markup
- **CSS3** — Styling, gradients, and glassmorphism effects
- **JavaScript (Vanilla)** — DOM manipulation and API handling
- **[OpenWeatherMap API](https://openweathermap.org/api)** — Real-time weather data
- **Font Awesome** — Icons

## 🚀 How It Works

1. User enters a city name in the search box
2. App calls the OpenWeatherMap API with the city name
3. Response data (temperature, humidity, wind speed, weather condition) is parsed
4. UI updates dynamically with the results and matching weather icon
5. Invalid city names trigger a friendly error message
